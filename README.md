# RECOP — landing page

Landing estática para **RECOP**: presenta el proyecto y da acceso al repositorio.
React + Vite + CSS puro. Estética experimental (magenta, glitches, scanlines).

## Correr

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estructura

- `src/content.js` — todo el copy y los datos del proyecto (editá acá).
- `src/components/Logo.jsx` — **logotipo provisional**: un dango de tres bolas.
  Reemplazarlo por el logo oficial cuando la marca esté lista.
- `src/components/Glitch.jsx` — efecto de texto roto.
- `src/index.css` + `src/App.css` — variables de color (magenta `--magenta`) y estilos.
